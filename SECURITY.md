# Security Policy — subgrup-prop7.1

## Reporting a Vulnerability
If you discover a security vulnerability, please email polcg10@gmail.com. Do not open a public issue.

## Security Considerations
- This is an academic Java recommendation system with a Swing GUI.
- Persistence is file-based — the application reads and writes local data files. Ensure data files come from trusted sources.
- There are no network or web components.
- Not intended for production use.
